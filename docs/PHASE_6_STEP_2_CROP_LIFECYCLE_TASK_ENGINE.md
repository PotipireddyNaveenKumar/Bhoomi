# BHOOMI V2 — PHASE 6 STEP 2
# CROP LIFECYCLE + FARM TASK INTELLIGENCE ENGINE

## 1. Executive Summary

Phase 6 Step 2 hardens the agricultural crop lifecycle and farm task intelligence layer for BHOOMI V2. It bridges deterministic biological crop calendars, real-world farm conditions, and weather/market realities to answer the central farmer questions:
- **"What should I do today?"**
- **"What should I do this week?"**
- **"What is pending or overdue?"**

This implementation enforces strict agronomic governance:
- **Zero Hallucinated Calendars**: Crop stages are deterministically computed from sowing/transplant dates and validated ICAR/SAU stage durations, never generated by LLM guesswork.
- **Strict SafetyEngine Precedence**: Chemical sprays and prohibited substances are filtered prior to task generation. Rice remains locked to `RESEARCH_ONLY`.
- **Context-Aware Dynamic Replanning**: Tasks react to real-time precipitation forecasts (postponing spray and irrigation) while preserving task audit histories.
- **Traceability and Freshness**: Every task links to active `FarmState`, verified RAG sources, `trace_id`, and data freshness statuses.

## 3. Crop Lifecycle Implementation (`CropLifecycleService`)

The biological lifecycle engine models crop progression through 7 standardized stages:
$$\text{SOWING} \longrightarrow \text{GERMINATION} \longrightarrow \text{VEGETATIVE} \longrightarrow \text{FLOWERING} \longrightarrow \text{FRUIT\_DEVELOPMENT} \longrightarrow \text{MATURITY} \longrightarrow \text{HARVESTED}$$

### Crop-Specific Validated Calendars
Calibrated with ICAR-IIHR, ICAR-NRCB, ICAR-CPRI, ICAR-IIMR, and SAUs (ANGRAU, TNAU):
1. **Chilli** (155-160 days): Teja, Byadgi, G4 varieties.
2. **Tomato** (125-140 days): Arka Rakshak, Pusa Ruby.
3. **Banana** (360-365 days): Grand Naine, Robusta.
4. **Corn/Maize** (110 days): Dharmavaram hybrid.
5. **Potato** (105-110 days): Kufri Jyoti.
6. **Rice** (145-150 days): BPT-5204 (Designated strictly `RESEARCH_ONLY`).

### Uncertainty and Missing Sowing Date Handling
- If `sowing_date` is `None`: Returns `current_stage="UNKNOWN"`, `stage_confidence=ConfidenceLevel.LOW`, `data_source="unknown"`, explicitly declaring that accurate biological calculation requires a recorded date.
- If variety duration is unrecorded: Evaluates standard cultivar baseline and marks `stage_confidence=ConfidenceLevel.MEDIUM`.

### Deterministic State Machine
```
   [PLANNED] --------> [DUE] --------> [IN_PROGRESS] --------> [COMPLETED]
       |                 |
       +-------> [POSTPONED] (Weather / Soil)
       |                 |
       +-------> [SKIPPED]   (Farmer Decision)
       |
       +-------> [CANCELLED] (SafetyEngine Blocked)
       |
       +-------> [EXPIRED]   (Window Elapsed)
```
- **Validation Guards**: `complete_task` rejects terminal states (`CANCELLED`, `EXPIRED`).
- **Dependency Guard**: A task with unresolved prerequisite `dependencies` cannot be completed or transitioned to `DUE`.

## 6. Deduplication & Postponement Engine

### Deduplication
Prevents duplicate task proliferation when daily briefing queries execute repeatedly:
- Unique signature: `(farm_id, crop.lower(), task_type.value, trigger.lower(), due_at[:10])`
- Preserves existing task lifecycle states (`COMPLETED`, `POSTPONED`, `IN_PROGRESS`) rather than overwriting farmer progress.
- Dynamically updates active `trace_id`, `weather_freshness`, and source evidence.

### Weather-Dependent Postponement
- When `rain_probability >= 40%` or `rainfall_mm >= 12.0mm`:
  - Irrigation tasks automatically transition to `POSTPONED` with clear justification: *"Precipitation expected (X% probability). Re-evaluate in 48 hours."*
- When `rain_probability >= 50%`:
  - Foliar spraying tasks transition to `POSTPONED`: *"High rain probability. Spraying postponed to avoid foliar nutrient wash-off."*
- Original due dates are never silently modified: `old_due_time` and `postponement_reason` are persisted.

## 7. SafetyEngine Precedence & Crop Health Integration

### Banned Chemicals & Toxicity Filtering
- All candidate tasks evaluate through `SafetyEngine.evaluate(task_text)`.
- If a prohibited agrochemical is detected (e.g. Monocrotophos, Paraquat, Chlorpyrifos), the task is immediately marked `BLOCKED_UNSAFE` with status `CANCELLED` and detailed warnings.

### Crop-Health Diagnostic Confidence SOP
- When disease detection confidence is below 80% (`confidence < 0.80`) or unconfirmed:
  - Generates a primary `FIELD_INSPECTION` task: *"Diagnostic confidence is uncertain. Physically inspect 10 affected plants."*
  - Any subsequent treatment or spraying task is configured with a strict dependency on the completion of the physical inspection (`dependencies=[inspection_task_id]`).

### Rice Research-Only Guard
- The Rice disease model is isolated under `RESEARCH_ONLY`.
- No farmer-facing chemical spraying task is generated for Rice.
- All Rice tasks carry `[RESEARCH ONLY]` titles and `safety_status="RESEARCH_ONLY"`.

## 8. Daily Farm Briefing & 7-Day Weekly Plan

### Daily Briefing (`DailyFarmBriefingService.generate_today_briefing`)
- Consumes real `FarmTask` instances and `DecisionPlan`.
- Delivers voice-ready multilingual briefings (Telugu and English) prioritizing the single most urgent task of the day.

### Weekly Plan (`DailyFarmBriefingService.generate_week_briefing`)
- Projects a 7-day operational schedule.
- Automatically tags tasks with `[WEATHER_DEPENDENT]` when upcoming precipitation probability exceeds 40%.
- Outlines expected operational expenses, price outlook, and pollinator safety guidelines.

---

## 9. Dynamic Replanning & FarmMemoryV2

- **Dynamic Replanning** (`TaskIntelligenceEngine.dynamic_replan`): When live sensor or forecast feeds detect weather shifts (e.g. sudden rain), active tasks are re-evaluated and transitioned without manual farmer intervention.
- **Audit Logging** (`FarmMemoryV2`):
  - Every created task logs a `task_created_{task_id}` memory event.
  - Every completion logs `task_completed_{task_id}` with timestamp, farmer ID, and completion source (`farmer_voice`, `farmer_dialogue`, `api`).
  - Postponements and skips log structured audit records for longitudinal farmer compliance analysis.
