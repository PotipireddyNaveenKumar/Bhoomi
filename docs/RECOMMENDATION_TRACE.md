# BHOOMI V2 — Recommendation Trace & Decision Auditability

## 1. Traceability Architecture
Every recommendation generated by BHOOMI V2 creates an immutable `RecommendationRecord` in `RecommendationTraceStore`.
This guarantees accountability, explainability, and post-harvest evaluation.

```json
{
  "recommendation_id": "rec_3a8f9c1b",
  "farmer_id": "farmer_demo_1",
  "farm_id": "farm_1",

  "intent": "farm_manager_turn",
```

## 2. Farmer Feedback Loop
Recommendations capture farmer feedback:
- **Was this recommendation useful?** (`USEFUL`, `PARTIAL`, `NOT_USEFUL`)
- **Did you execute the action?** (`ACCEPTED`, `MODIFIED`, `REJECTED`)
- **Actual Harvest Outcome**: Yield, actual sales price realized, actual profit.

This data builds BHOOMI's longitudinal data flywheel without exposing sensitive farmer PII.
